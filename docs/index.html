Summary
    Example output. Owners are only assigned if they were on the call. Tasks under 60% confidence are flagged and left unassigned.

    One playbook per team, written in plain English

    A playbook tells Claude what counts as a task for that team. To add a team, copy a file and edit the text. No code.

    Run it on your own calls

    Granola is always the source. Pick how the notes reach Minuta. Both need a Claude API key and a Linear workspace. Full guide in the README.

    Direct · Granola Business or Enterprise

    No Zapier, no server. GitHub's free scheduler runs Minuta every hour and collects new notes from your team folders.

    • Make a private copy of the repo
    • Create a Granola API key
    • Add GRANOLA_API_KEY, ANTHROPIC_API_KEY and LINEAR_API_KEY as GitHub secrets
    • Run it once from the Actions tab

    Zapier · any paid Granola plan

    Tasks appear as soon as the note is saved. Needs a Zapier account and a server for the webhook.

    • Deploy to Vercel (the api/ folder is ready) or run npm start
    • Add your Claude and Linear keys and a webhook secret
    • Zap: Granola "Note added to folder" → POST to your webhook
    • Set linear_team and folders in each playbook

    Design decisions

    Evidence for every task

    Each task carries the quote it came from, so nobody has to rewatch the call to check what was promised.

    Built not to over-assign

    • Only people on the call can be assigned.
    • Low-confidence tasks are labelled "Needs review".
    • Review mode sends every task to triage first.

    Consent and privacy

    Tell everyone on the call it is being recorded (required under GDPR and many other laws). Transcripts go only to Claude and Linear. Minuta stores nothing.
